# JUNTING ARCHIVE · 360° 作品穹顶(单页)

整站只有一页:一个 360° 球面画廊,50 张作品贴满内壁,载入自动入场,可拖拽旋转、点击看大图。
前后没有任何额外页面。占位卡由浏览器现画,不依赖图片文件,所以永远不会空白。

## 打开

请在整个 Felix 网站的项目根目录运行 `npm run dev`,然后在浏览器访问:

```text
http://127.0.0.1:52124/portfolio/index.html
```

必须走本地服务器 —— 直接双击 index.html 会被浏览器安全策略拦截(ES Module)。
库(three.js / GSAP)全在 `vendor/`,离线也能跑,不连任何 CDN。

## 改站名 / 分类 / 数量

全在 `app.js` 顶部 `CONFIG`:
- `brand` 站名(环形文字);左上角水印、页脚署名在 `index.html` 里搜 `JUNTING` 改;
- `cats` 分类名(VISUAL / BUILD);
- `counts` 每类占位卡数量,合计 = 作品总数(现为 34 + 16 = 50)。

## 调手感

同样在 `CONFIG`:球半径 `radius`、视角 `fov`、拖拽 `dragK`、惯性 `inertia`、自转 `autoSpin` 等,每项都有注释。

## 换成真照片

图片放在 `images/`，在 `collection.js` 按固定位置编号登记 `src`、原图宽高 `w` / `h`、图片描述 `title`。球面缩略图和点击大图共用这一条记录，未登记的位置继续使用占位卡；不改变球面布局或拖拽方式。

当前已放入 16 张（a-001 至 a-016）：第一批 5 张，第二批新增 11 张，保留原图及图内文字。穹顶总计 50 个位置，还剩 34 个待补：视觉卷 18 个、开发卷 16 个。下一批视觉作品从 a-017 开始，避免覆盖已收录图片。GitHub 开发项目另以独立列表呈现在主站作品区，不占用影像卡位。
